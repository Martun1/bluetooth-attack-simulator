# Bluetooth Attack Simulator (Educational)

Educational C++ project that simulates Bluetooth attacks and explains defensive techniques.
No real devices are affected.

## Features
- Simulated Bluetooth device scanning
- Deauthentication attack simulation
- Signal interference simulation
- Security defense explanations

## Purpose
This project is built for learning cybersecurity concepts and ethical hacking principles.

## Disclaimer
This tool is strictly educational. No real Bluetooth attacks are performed.
